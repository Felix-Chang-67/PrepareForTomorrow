# KEDAMONO_AYAKASHI LRC 校准

用 `KEDAMONO_AYAKASHI_24bit_48kHz.wav`（168.30 s）重新校准 `KEDAMONO_AYAKASHI_v2.lrc` 的时间轴。

- `KEDAMONO_AYAKASHI_v2.lrc`：原文件（未改动，用于对照）
- `KEDAMONO_AYAKASHI_v2_calibrated.lrc`：校准后的文件。只改时间戳，歌词、译文、标签、行数、编码（UTF-8 无 BOM、LF 换行）都与原文件一致。

## 时间戳的定义

- 每行时间 = 该行第一个音素的起点，包括辅音：
  - 擦音 sh/s/h 从摩擦噪声开始算（如 処方箋、救われたい、勝利條件）
  - 鼻音 n 从鼻音开始算（如 ノーサイド、脳細胞、何すりゃいい）
  - 塞音 t/k/b/d 从除阻（爆破）开始算
- 没有加提前量。如果希望歌词提前显示，可以在文件头加 `[offset:+200]`（单位 ms，正数 = 提前）。
- 空行（`[mm:ss.xx]` 后无文字）放在上一句人声衰减结束的时刻。

## 方法

1. 用 Demucs（htdemucs_ft）分离人声。
2. 粗定位，三种方法互相印证：
   - Whisper large-v3 强制对齐（stable-ts）
   - Whisper 自由转写（带词级时间）
   - MMS CTC 音素对齐（读音用人工标注的罗马字，如 脳細胞 → nousaibou）
3. 逐个边界精修，分辨率 5–25 ms，依据：
   - 人声频谱图
   - 四个频段的能量：鼻音表现为低频强、中频弱；擦音表现为高频强于中频；塞音表现为全频段闭塞后爆破
   - pYIN 音高
   - 伴奏节拍网格（约 143.5 BPM）
4. 一致性校验：
   - 两段副歌的互相关偏移恒定：第 14–17 行 ↔ 第 32–35 行为 +68.08 s，第 13 行 ↔ 第 28 行为 +56.08 s
   - 对应行用同一种发音线索定位，结果自洽
   - 重复段（脳細胞、I hate me）按每 2 拍一次的周期核对

精度估计：
- 清晰起音的行（静音后起唱、塞音、擦音）约 ±30 ms
- 连唱中元音或鼻音开头的边界约 ±60 ms
- 第 11 行（经过效果处理的人声）约 ±100 ms
